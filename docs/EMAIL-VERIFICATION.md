# Email verification launch check
Hosted Supabase project qwthqnvkusuneifieykr. Website requests Supabase OTP and accepts numeric verification codes or secure links; ordinary signup also accepts a code and supports resend. Templates in supabase/email-templates are not automatically deployed. In Supabase Authentication > Email Templates, paste confirm-signup.html into Confirm signup, magic-link.html into Magic Link. Both include {{ .Token }}; keep link fallback. In Authentication > SMTP Settings confirm a verified custom SMTP sender is configured. The built-in Supabase SMTP is restricted to authorized team addresses and has a small quota. Verify DNS and provider delivery logs. Keep email confirmation enabled. Test both signup and trial with a fresh non-team inbox. The production sender configuration was not changed through the available connector, which has no auth-config write action.
