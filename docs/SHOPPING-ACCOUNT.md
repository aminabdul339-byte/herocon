# Shopping account P1
Customer routes /cart, /orders, /warehouse, /parcels. All authenticated users have access; live and test records use separate owner-hashed private Blob prefixes. The customer read API authenticates the user server side and never accepts a client owner ID. The live snapshot writer is internal and not called by any public route; real Stripe/Hiobuy workers still need integration. Existing test orders are imported read-only into the new private workspace; prior data is preserved. New test checkouts include image and product path snapshots when provided. Legacy orders may have no images. 
Test mode: /orders?test=1, owner only. Individual item arrival; multi-order packing reserves items atomically by immutable revision; shipping due stays in warehouse; simulated payment moves them to parcels; dispatch and delivery separate; simulated return and cancellation requests do not issue refunds. Actual freight estimates are read-only, declared test weight, no real wallet writes. Payment records are downloadable plain text, not tax invoices. QC photos shown only if actual stored URLs exist; no fabricated images. Existing test checkout leaves the real cart unchanged deliberately. 
Launch gates: wire live provider/package/receipt data and verified Stripe webhooks to account records, production checkout and shipping actions, actual QC, returns support and carrier tracking. Do not enable public payments until verified.
